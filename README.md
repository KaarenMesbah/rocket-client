# Telegram Client — Cordova

A hobby Telegram client built with **Apache Cordova**, originally made to run on an **iPhone 5**. It also works as a web application in a browser.

This project is the **frontend/client side** of the application. The backend/server is maintained separately in another repository.

This repository contains the client-side application. 
check https://github.com/KaarenMesbah/rocket-api for the backend!

# About

This is a personal hobby project created to experiment with **Cordova, WebSockets, Telegram's API, and building applications for older mobile hardware**.

The project was originally targeted at the iPhone 5 and iOS 10, but the frontend can also be run directly in a modern web browser.
